O plano da semana

Esquece o rover e o multicorpos por enquanto — aquilo vem lá na frente. Esta semana é base de Godot, do jeito que o professor pediu: assistir o material, criar o repositório e conhecer a linguagem do Godot e como ela usa outras linguagens. Três coisas, sem pressa.

01

Assistir o material

Ver os vídeos que o professor mandou e pegar a base do Godot. Dica que muda tudo: faça junto no editor enquanto assiste — não só assista de braços cruzados.

  • Assista na ordem, pausando pra reproduzir cada passo no Godot aberto do lado.
  • Se travar num ponto, anota a dúvida em vez de parar tudo — segue e volta depois.

02

Criar o repositório

Colocar o projeto no GitHub. Além de organizar, é a base do futuro site de documentação (GitHub Pages) que você planeja.

  • Cria o repo no GitHub (pode ser privado no começo) e escreve um README curto: o que é o projeto e qual é a sua frente.
  • Na criação, escolhe o template de .gitignore chamado "Godot" — ele já ignora a pasta .godot/ e afins.
  • Faz o primeiro commit com o projeto do carrinho que você já montou.
03

A linguagem do Godot (e as outras)

Entender o GDScript — a linguagem nativa — e como o Godot deixa você usar outras linguagens. Esse item conecta direto com o seu tema (veja o box abaixo).

  • GDScript: parecida com Python, feita pra viver dentro do editor. É por onde começar.
  • As duas que te interessam: GDScript e C++ (via GDExtension).
  • Faça o "Learn GDScript From Zero" (interativo e gratuito) e dá uma lida na página "Other languages" da doc oficial.
cursoGDQuest — "Learn GDScript From Zero" (interativo, grátis) docGodot — "Other languages" (GDScript, C#, C++)
◈ Por que o item 03 não é aleatório

O GDExtension — o mecanismo que carrega código C++ nativo dentro do Godot — é exatamente como a ExoPhysics (que é C++) vai se plugar na ExoTerra. Ou seja: entender "como o Godot usa outras linguagens" é entender a fundação técnica da integração do seu Tema 1. Não precisa dominar agora — só reconhecer o conceito já te deixa à frente.

Sem rover, sem juntas, sem tabelas. Só três tarefas tranquilas pra fechar a semana.
